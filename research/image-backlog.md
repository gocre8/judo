# Image Backlog

Working checklist for representative and dedicated technique imagery.

## Image Use Rules

- Prefer accurate move-specific images over generic position boards.
- Use shared branch boards when a cluster is useful but per-move art is not ready yet.
- Avoid images with baked-in labels, visible third-party branding, logos, or watermark-style marks.
- Avoid using generated images as technical proof. Treat them as study visuals that still need human review.
- Do not map an image to a position unless the position is clearly correct.
